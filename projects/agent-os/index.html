3-Panel Structure

Agents, chat and artefacts each get their own panel in one workspace.

Mental Model

The workspace reads from left to right: agents are started and resumed on the left, the work happens in conversation in the centre, and the artefacts the agents create collect on the right.

Standard

Agents, chat and studio panels at their default widths.

Subagent + Chat

The agents panel expands to show a sub-agent’s work next to the main chat.

Chat + Reading/Writing

The agents panel closes so an artefact can be read or edited next to the chat.

Panel States

Each side panel has three states: closed, default and expanded. Closed, it narrows to a rail that keeps status and artefact icons in view. Expanded, it makes room for a sub-agent’s work or an open artefact.

Agents Panel

New agent is the main action. Earlier agents are listed by date, each with a coloured status dot and a one-line update. Expanding the panel opens a read-only view of a sub-agent’s work.

Studio Panel

Artefacts the agents create collect here and can be filtered by type: text and analysis, charts and visuals, presentations, and data and models. Expanded, an artefact opens as a document that can be edited, commented on or refined with Ask AI.

Chat Panel

The conversation with the selected agent. It opens with suggested tasks and a place to add context, and during a run it shows the agent’s progress.

Key takeaways from the journey

Designing for clarity as agents grow more capable

Long Geng

PwC AI CoE

AgentOS taught me that clarity comes from hierarchy, not from hiding complexity. The three-panel workspace gave agents, conversation and artefacts each a clear place, and the execution work applied the same thinking to what agents do over time. The most important shift wasn’t removing execution details — it was deciding when they should be visible. By keeping progress understandable, outcomes prominent and deeper activity available on demand, I developed a design principle that can extend beyond AgentOS to other agent-driven experiences.
